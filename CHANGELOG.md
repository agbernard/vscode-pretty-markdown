# Changelog

## [0.0.1] - 2026-11-10

Initial release of Pretty Markdown, based on [Markdown Appealing](https://github.com/rayeddev/markdown-appealing) v0.10.1 by rayeddev (MIT).

### Changed
- Preview webview now has a restrictive Content-Security-Policy
- Raw HTML in markdown is no longer rendered
- Mermaid `securityLevel` set to `strict`
- Removed Google Fonts imports from all themes (no external requests)
